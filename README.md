A one-line text message from a smart fridge to its owner at 3am: the fridge has been awake all night, it saw what happened to the last slice, and — worst of all — it gossips with the microwave. `main.py` (Python standard library only) writes that single line to `/output/entry.txt`, after checking it is one non-empty line of at most 140 characters.

## Run it

```sh
python3 main.py
```
